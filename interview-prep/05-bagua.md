## 一、LLM 基础

1. **Transformer 是什么？** → 自注意力机制，并行计算，编码器+解码器；大模型基础架构
2. **注意力机制原理？** → Q(查询)/K(键)/V(值)：Q×K 算相似度 → softmax 归一化 → 加权 V；"让模型知道该关注输入的哪部分"
3. **tokenizer 是什么？** → 文本切最小单元；英文≈词/子词，中文≈字/词；API 按 token 计费
4. **上下文窗口是什么？** → 模型一次能处理的最大 token 数；超限截断（你 RAG 项目解决的就是这个）
5. **温度 temperature 作用？** → 控制随机性：低=确定/保守，高=发散；事实任务用低温度
6. **模型为什么会产生幻觉？** → 生成式统计预测，训练数据外/知识过时/提示不明确时"编造"；缓解：RAG、引用溯源、拒答、限定格式
7. **大模型为什么需要 Prompt Engineering？** → 模型按统计规律响应，明确角色/要求/示例/格式约束输出质量
8. **DeepSeek 和 GPT 的区别（答得出来加分）** → API 兼容 OpenAI 格式；中文/推理场景表现；价格；开源权重

## 二、RAG（结合你的项目讲）

1. **RAG 流程？** → 离线：文档→切分→向量化→入库；在线：问题→向量化→检索→重排→拼 prompt→生成
2. **为什么用 RAG 不用微调？** → RAG：知识可更新、可溯源、成本低、不用训练；微调：改行为风格、成本高
3. **切分策略有哪些？** → 固定长度/段落/语义/递归；权衡：语义完整性 vs 检索粒度
4. **Embedding 模型怎么选？** → 语言匹配（中文用中文模型）、效果（榜单）、尺寸/速度/成本
5. **向量检索快在哪？** → ANN（近似最近邻）如 HNSW：图结构跳转，不是全量比较
6. **混合检索为什么好？** → 向量懂语义、BM25 懂精确词，互补；怎么融合（归一化+加权）
7. **重排是干什么的？** → 召回宽（top-20）→ 精排（top-4）；重排器更精准但更贵，只重排少量候选
8. **怎么评估 RAG 系统？** → 检索侧：top-k 命中率（你的指标）；生成侧：答案正确性/引用准确率；自建评估集
9. **回答怎么溯源防幻觉？** → 引用编号+来源定位；prompt 约束"只依据资料"；拒答阈值

## 三、Agent（结合你的 Demo 讲）

1. **Agent 核心循环？** → 规划→工具调用→观察结果→再规划（ReAct）
2. **工具调用怎么实现？** → 模型输出结构化意图（JSON/function call）→ 程序校验执行 → 结果回填
3. **Function Calling 和手写 JSON 协议？** → 原生：平台强制格式；手写：自己控制校验/重试/兼容多模型
4. **Agent 的规划策略？** → ReAct（边想边做）/ Plan-then-Execute（先计划后执行）/ 反思（自我评估修正）
5. **记忆怎么设计？** → 短期（会话历史）/ 长期（向量库检索）；全量 vs 摘要
6. **Agent 失败怎么办？** → 格式校验兜底、错误具体反馈重试、最大轮数防死循环、日志追踪
7. **多 Agent 协作？** → 主控+子任务分配；各有角色，结果汇总（了解即可，不问不展开）

## 四、向量数据库

1. **向量数据库干什么？** → 存向量+相似度检索；比暴力遍历快
2. **索引原理（HNSW）？** → 分层图：高层粗跳、低层精查；近似但快
3. **相似度度量？** → 余弦（方向）/ 欧氏（距离）/ 内积；embedding 常用余弦
4. **Chroma 特点？** → 轻量、本地持久化、API 简单、适合原型；生产：Milvus/Qdrant/Weaviate
5. **向量检索的坑？** → 维度灾难、归一化、索引构建耗时、增量更新

## 五、Python 工程

1. **GIL 是什么？** → 全局解释器锁：同一时刻一个线程执行 Python 字节码；CPU 密集多线程无效，多进程/异步
2. **异步 async/await？** → 单线程协程，IO 等待时切换；适合网络请求（你调 API 的场景）
3. **列表推导/生成器？** → 生成器惰性求值省内存（大文件逐行读）
4. **装饰器？** → 函数包裹函数，日志/鉴权/重试通用
5. **requests 超时设置？** → timeout=(连接,读取)；不设会一直挂（你修过联网卡死，关联讲）
6. **异常处理最佳实践？** → 捕获具体异常、finally 释放资源、不吞异常不裸 except
7. **字典 vs 列表查找？** → dict O(1) 哈希；大集合用 set/dict 去重提速（关联你的算法题）

## 六、FastAPI / 部署

1. **FastAPI 特点？** → 异步支持、自动文档（/docs）、类型校验（Pydantic）
2. **生命周期？** → startup/shutdown 事件；模型加载放 startup 一次复用（你 engine 单例思想）
3. **和 Flask 区别？** → FastAPI 原生 async + 类型校验 + OpenAPI 文档；Flask 更简单传统
4. **怎么部署？** → Uvicorn 起服务 → 反向代理（Nginx）；Docker 容器化；云端（Streamlit Cloud/云服务器）
5. **并发请求怎么处理？** → 异步接口 + 连接池；模型/数据库连接复用；限流
6. **配置/密钥管理？** → 环境变量/secrets 文件，不提交到 git（你 .gitignore 排除 secrets——关联讲）
