什么是 Token？
Token（词元）是大模型处理文本的最小单位。英文里一个单词通常是一个或两个 Token，中文里一个汉字大约是一个 Token。模型不是按"字"阅读，而是按 Token 阅读。API 计费也按 Token 数来算。

大模型是怎么工作的？
大模型（LLM）本质上是一个"超级预测器"：它根据你给它的前文，预测下一个 Token 最可能是什么，然后一个接一个地生成。它并不"理解"世界，而是学会了海量文字中的统计规律。训练数据越多、参数越大，预测就越像人。

什么是 Prompt？
Prompt 就是你给模型的指令和输入。同样的模型，Prompt 写得好不好，回答质量差别很大。写 Prompt 的常见技巧：给模型明确角色、说明要求、给出示例、限定输出格式。

什么是上下文窗口？
上下文窗口（Context Window）是模型一次能"看到"的 Token 上限。比如 128K 窗口就是一次能处理约 12 万 Token 的输入。超过上限的内容会被截断。这也是为什么不能把整本书直接塞给模型。

什么是 RAG？
RAG（检索增强生成）是让大模型先"查资料"再"回答"的技术。流程是：把资料切成小块存起来，用户提问时先找出最相关的几块，把它们拼进 Prompt 再让模型回答。好处是回答有依据、能更新知识、不容易胡编。

什么是 Embedding（向量）？
Embedding 是把一段文字转换成一串数字（向量），让意思相近的文字在数字空间里距离也近。比如"苹果"和"水果"的向量距离近，"苹果"和"汽车"的距离远。RAG 里的"找最相关资料"就是靠算向量距离实现的。

什么是 Agent？
Agent（智能体）是能自己"规划-调用工具-行动"的 AI。它不只是回答你，而是会拆解任务、调用工具（比如搜索、执行代码、访问数据库），再根据结果继续行动。ChatGPT 的联网搜索、Codex 帮你改代码，背后都是 Agent 的思路。

什么是 API？
API 是程序之间通信的接口。你写的 Python 代码通过 HTTP 请求调用 DeepSeek 的 API，传消息进去，拿回答出来，就像点外卖一样。你自己的程序因此获得了"会说话"的能力。
