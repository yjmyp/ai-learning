# 求职战术与 AI 变现分析（2026-08-15 晚）

> 来源：抖音收藏夹 100+ 链接综合（秋招/实习、外企、Agent 强度、AI 赚钱、AI 观点）
> 结论一句话：方向不变（Python AI 应用开发/Agent），强度标准 = 原理能讲清 + 项目能演示 + 评估有数据 + 场景题能答；AI 赚钱现阶段不碰。

## 一、方向：不变，更聚焦
- 主方向：Python AI 应用开发 / Agent 开发。双非本科走 Agent 开发完全可行（多个视频标题印证："Agent 不再是博士生才能做"、"双非本科想做 Agent 开发"）
- 你的"上岸强度"定义 = **RAG 项目 + Agent 项目 + 评估体系**，三个都能讲深即可

## 二、Agent 岗"强度"共识（腾讯/字节/多家拆解汇总）
1. 原理能讲清：ReAct、规划、记忆、工具调用、反思——不是背概念，要能画流程、讲取舍
2. 项目能演示：上线可访问、有真实输入输出、能讲清"为什么这么做"
3. 评估有数据：任务成功率、工具调用正确率、检索命中率（Agent 评估工程化是强加分）
4. 场景题能答：给一个落地场景，能拆需求 → 选技术 → 排风险
5. 实习经历 > 面试技巧："面试表现再优秀，不如新增一段实习经历"

## 三、求职策略调整（重要）
- **时间**：8 月底投实习不晚（"6-7 月找不到实习很正常，8 月底再投"）；9-10 月秋招补录会再热闹；现在正是 27 届主战场
- **渠道分层**：
  - BOSS直聘：中小厂/日常实习/南京本地
  - 牛客：内推、面经、校招时间表
  - 实习僧：实习聚合
  - 应届生求职网/高校就业网：免笔试企业、央国企
  - 外企：官网/LinkedIn（外企对应届生放宽、二本友好、冷门外企招不到人）
- **外企路线新增**：Calix 凯易讯（A 档第一名）就是外企；江浙沪外企池可再挖（日企月薪过万、低内卷外企、二本友好外企）
- **优先投"免笔试"企业**：简历过了就约面，适合项目强、笔试弱的你
- **简历原则**：没有项目可写才是原罪 → 你已有 1 个上线项目，再补 1 个 Agent 项目；0 实习拿 offer 的案例靠的就是项目深度 + 面试
- **央国企**：可作保底备选（27 届秋招捡漏），但 AI 岗少、节奏慢，不作为主线

## 四、学习计划微调（已并入 PLAN v4.1）
- 阶段 A（RAG v2）：eval 评估集 = "评估工程化"的入门证据 ✅ 已列入
- 阶段 B（Agent 项目 2）：新增 **Agent eval**（任务成功率/工具调用正确率）+ 演示视频
- 阶段 C：新增 **落地场景题练习 10 道**（拆需求→选技术→排风险）；简历增加"外企向"版本
- 投递节奏不变：8/21 首投 A 档 + B 档（含外企 Calix）→ 9/10 二投 → 9/16 批量 + 秋招网申

## 五、AI 赚钱：客观结论（现阶段不碰）
- 大量"AI 搞钱"内容是标题党/卖课引流，警惕（"千万不要教别人赚钱"本身就是讽刺）
- 真正可信的信号：VibeCoding 变现 = 用 AI 快速做出产品并交付（本质是"有能力做东西"）；普通人靠实操 + 执行力
- 对你：9-10 月主任务是求职，赚钱副线投入不划算；等有实习/项目背书后再考虑（接小活/交付 demo）
- 防割：不买课、不信"100w"标题；免费资源（GitHub/官方文档/开源项目）足够
