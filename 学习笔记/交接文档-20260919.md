## 6. 已经确立的教学方式（请照这个来）

1. **对照式**：左边讲概念（为什么），右边指他项目里的具体代码（哪一行），中间一张对照表
2. **讲代码七层**（explain-my-own-code 技能）：用途 → 在项目里的位置 → 用真实输入走一遍流程 → 概念 → 细节 → 边界 → **让他复述**
3. **一屏一图**（doceo 技能）：一句话答案放最上面，一张图，一个比喻，平白语言，产出自包含 HTML + 笔记
4. **每讲必复述**：讲完给 2 到 3 个问题让他用自己的话答，答不出就重讲那一块
5. **先全景再细节**：用 `learning\maps\rag-knowledge-map.md` 那张图定位"这讲在第几层"
6. **一次一小步**：一讲只讲一件事
