# 学习守则 v1（2026-08-17）—— 对抗五个毛病的操作系统

> 用法：每天开始学习前读一遍（1 分钟）。Codex 是执行者，负责按本守则拦截你——被拦不是针对你，是守则在工作。

## 启动仪式（每天 1 分钟）
1. 读本守则一遍。
2. 说出今天的**一条线**（只一条）+ **完成定义**（≤3 条，达到即停）+ **检验方式**（怎么算学会/做完，必须先写出来）。
3. 第一件事必须是**执行动作**（跑代码 / 写代码 / 投递 / 交证据），不是讨论或检索。

## 目标-检验闭环（2026-08-19 用户提出，正式入册）
- **学前（1 分钟）**：一条线 + 完成定义 + 检验方式——检验方式没写出来，目标不生效。
- **学中（卡点即问）**：碰到不会的立刻停下，用卡点格式问 Codex："卡在哪 + 试过什么"；Codex 讲完，自己复述一遍确认真懂，再继续。
- **学后（当场验收）**：按学前写的检验方式跑一遍，产出完成证据（三句话 / 输出对比 / diff / 记录）。不达标就缩小范围重来，不无限返工。
- **职责划分**：目标 = 自己提（提不出时 Codex 给 2-3 个候选，选或改，不代定）；审目标 = Codex（太大/不可测/多件事 → 打回缩小）；提问 = 自己问（卡点格式）；验收 = 自己跑 + Codex 复核。
- 为什么这条是克星：偏印"多学少成"的病根就是只定方向不定验收——先写检验方式，学没学会当场见分晓。

## 五条铁律
1. **计划冻结 + 每日 1 次修订权**：v4.4 是唯一计划；每天最多允许 1 次整体计划修订（仅限吸收新信息/新证据，须写明依据），除此之外一律否决；每天"思考/讨论"≤30 分钟，超时 Codex 喊停。
2. **60 分先上**：每个任务先写完成定义，达到即停；同一产出最多改 2 版，第 3 版必须隔天（冷却期）。
3. **单线程**：一次只学一个文件/做一件事；未完成不换话题；想换线必须先交**卡点**（卡在哪、试过什么）或**完成证据**。
4. **AI 写初版，你审 + 改 + 讲**（2026-09-14 修订，用户授权）：项目代码由 Codex 写初版；你必须做到三件事——① **改动实验**（改一个地方 → 先预测 → 跑 → 对比结果）；② 每个文件能用自己的话讲清**输入、输出、失败会怎样**；③ 讲不清的地方当场标出来问，直到讲清为止。**副路 A**：每天 20 分钟「抄 → 改 → 默写」语法练习，从 3 行代码起步。
5. **事实代替想象**：焦虑先写进焦虑箱（一行事实 + 一行想象），想象不采取行动；说话格式="当前事实是…，下一步是…"，禁用"感觉完了/慢了/不行了"。

## 完成证据（每天至少交 1 个）
- 三句话讲透一个概念（口头/文字）
- 自己写或改的代码段（diff）
- 改动实验的输出对比
- 投递/面试的真实记录
