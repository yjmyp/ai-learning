## 二、对 AI 本身的思考（趋势信号）

1. **Agent 平民化**（大模型小黑「Agent 不再是博士生才能做」）：Agent 从研究变工程 → 岗位爆发（腾讯独立岗、字节独立岗）→ 现在是窗口期，2-3 年后供给涌进
2. **应用形态迁移**（原点「超级 App 围墙坍塌」+ 李健「未来三年 AI 终端爆发」）：入口从 App → Agent/终端（手机/眼镜/机器人）→ "做一个 App"的旧逻辑被"做一个垂直场景 Agent/工作流"替代
3. **工具民主化**（水球泡「草根掀翻正规军」+ VibeCoding + Cursor/Claude Code 进 JD 必备项）：个人+AI ≈ 小团队 → 护城河从"会写代码"变成"会定义问题 + 会选型 + 会评估"
4. **成本与上下文仍是硬约束**（叶客「无限 Token 满足不了所有人」）：记忆压缩、防幻觉、成本控制是长期工程能力（字节面试原题）→ "会调 API"的人多，"会控成本"的人少，这是差异化
5. **技能化/自我扩展**（认知觉醒转 Skill + 「成熟的 AI 要学会自己介绍自己」+ 「让 agent 自己赚米」）：个人方法论 → Skill → 可复用资产；MCP/Skill 协议将成标准（腾讯考 MCP/A2A 印证）
6. **结构性转移，不是消失**（「计算机是下一个土木？」+ 腾讯 935 岗中 469 个与大模型相关）：传统 CRUD/前端在被压缩（「AI 对前端冲击」），AI 原生岗位在扩张 → 关键不是"是不是计算机"，是"是不是 AI 原生能力"

## 三、未来推演（对 2026-2027 求职者的意义）

- 2026-2027 = **Agent 工程化窗口**：独立岗位 + 评测刚起步（青云课题"Agent 前沿评测"）+ 框架开源化 → 现在把 Agent 工程做深正好踩点
- **垂直场景 Agent > 通用 App**：信息调研、行业分析、求职助手、领域咨询（命理/教育/健康）这些"数据密集+流程化"场景最先落地
- 个人竞争力三层：**认知（选赛道）→ 作品（可演示+可评估+有边界）→ 工具（Codex/Cursor 熟练 + 会做 Skill）**
- 副业窗口真实存在（AI+网安、VibeCoding 交付、下沉市场服务、内容 AI 化），但门槛是"能独立交付"，不是"会提示词"

## 六、补充实证（2026-08-15 网络检索，用于替代无法抓取的抖音正文）

### 1. AgentGuide（GitHub adongwanai/AgentGuide）2026 求职路线——与本计划高度互证
- 阶段主线：Agent 坐标系 → Loop/工具/评测/上下文工程 → 框架 → **Evaluation / Observability / Safety**（"没有 eval 不行"）
- 项目模板三个：RAG/知识库 Agent、Multi-Agent 协作系统、**Agent 评估/Harness**——正是"行业雷达"+eval 的组合
- 评估玩法：任务集分三类（回归 50 / 对抗 30 / 多轮硬题 20），每个任务跑 ≥10 次，记录通过率；上线前 Phased Rollout 灰度

### 2. 企业级 Agent 评测实战（阿里云/字节/亚马逊拆解）
- 行业普遍"重构建、轻评测"，缺标准化度量 → 把"体验好坏"变成可量化指标，是稀缺能力
- LLM-as-Judge 有偏差，需要治理；四层防御体系；Harness 工程（用强 Agent 生成评测集）

### 3. 转型认知（王中阳等）
- 传统开发转 Agent 的最大挑战不是技术，是**思维转变：确定性编程 → 概率性编程**
- 策略：先守住 80% 基本盘（工程能力），再补 20% AI 专项，性价比最高
- 4 大误区：纯理论无实操、沉迷过时资源、轻信高价训练营、入门就啃论文

### 4. 2026 路线共识（多来源）
- 抓住"不变的东西"：**数据处理、系统设计、评估方法论**；多模态是下一波
- Web Research Agent 是社区公认的推荐入门项目（Agent-Learning-Hub 项目榜第 2）→ 行业雷达方向再次验证
- L0-L3 路线（阿里云）：先跑通低代码 → 再自己写循环 → 再工程化

### 3. Agent 评估的工程化路径被实测拿到（A7 笔记全文）

- 他的 Runtime"地基"清单：模型导入调用 / 多轮对话 / Agent Loop / 工具权限·预算·事件机制 / 会话回放 / 测评体系。

### 4. 交付流程 > 角色（A12）+ 自研 vs 框架（A13）

### 5. 让 Agent 赚钱：需求侧存疑（A14，8528 赞，全清单最高）

### 6. AI 编程实操实录（B4）与 LLM 底层资源确认（B5）

## 八、全量 122 条实测：跨主题新发现（2026-08-15 第五稿）

### 1. "岗位筛选 Agent"是评论区验证过的第一需求（求职包直接对口）
- C7/C10/C12/C21/C31/D1/D2/G5 等几十条高赞/高频评论是同一句式："@豆包 帮我筛 XX 城市 + XX 专业 + 学历 + 应届身份能投的公司/岗位"。
- C10（免笔试企业，1629 评）与 D1（冷门外企，10.7 万赞）是最大样本：用户在评论区直接向豆包下指令，说明**求职信息筛选已是用户默认该由 AI 干的活**。
- 结论：求职 skill 包第一入口不是"面试拷打"，而是**"给我一张能投的岗位清单"**（按城市/专业/学历/应届身份/免笔试/外企央国企过滤），做完这个就有真实用户价值；面试 Agent（A4）作为第二入口。

### 2. 秋招现实面被评论区反复证实
- 实习 > 面试表现（C19）：业务迭代快、团队没时间从头培养新人，学历证明你能学、实习证明你干过。
- 免笔试是真实红利（C10/C20）：简历过了就约面；"硕士才免笔试"也有吐槽（C28）。
- 焦虑真实存在：双非投不进四大（C21）、"双非本硕不配秋招"（C29）、项目写了已读不回（A4）、企业看年限（A8）。对策不变：项目 + 可演示作品 + 实习补位（8 月底窗口，C34）。
- 简历新规则：AI+ATS 简历系统七成简历第一轮被拦截（C35 相关推荐）→ 简历要用"场景+动作+数据"公式，正好接 AgentGuide 的 L1-L4 证据链。

### 3. 外企信息差是 27 届流量密码，也是求职包内容弹药
- D1 10.7 万赞 / D2 8.9 万 / D5 6.1 万：不卡学历外企（工厂类：六险一金、包吃住、加班法定支付、不卡经验）与专科可进外企（斯伦贝谢评论区真人案例）流量巨大。
- C12 奥地利 WLB 外企名单（红牛/施华洛世奇/安德里茨/AVL/奥特斯/TÜV）→ 求职包可做"外企白名单"数据模块。
- 现实提示（D3）：好外企不走招聘平台，靠内推/外包/官网 → 渠道策略要含官网直投 + 内推。

### 4. VibeCoding 与"工具民主化"被数据坐实，但边界同样清晰
- G17（贾维斯 2.9 万赞，非程序员用 Codex 造出成品）与 G14（伪需求焦虑 7.6 万赞）是两大情绪主线；G15（Terse 监控/省 token）说明工具链在补"可观测+成本"。
- 反面证据：F12 高赞"普通人折腾时间成本太高，烧 token 改来改去，市场已有更好产品，还是想好商业模式叫专业的人执行"；G23 评论"除了 workbuddy 其他都用不起，太费 token"。
