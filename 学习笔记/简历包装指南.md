# 简历包装指南（2026-08-17 · 检索实证 + 应用结论）

> 来源：AgentGuide 简历指南、阿里云《满分程序员简历》、OSC Agent 简历写法、牛客 AI 应用岗简历、新东方无实习简历策略
> 原则：只包装真实内容——每条都经得起面试追问。

## 一、检索到的核心写法（实证）

1. **求职意向加括号点明 AI 经验**："AI 应用开发实习生（具备 RAG 项目上线经验）"
2. **开头放作品集 + GitHub + 上线链接**（阿里云明确要求）
3. **无实习 → 项目经历板块上移**，放在教育背景之后，标题用"项目经历"避免"实习为空"
4. **动词开头、省略主语**：主导 / 设计 / 实现 / 构建 / 优化，不写"我负责了"
5. **写决策和技术方案，不写体力活**："负责数据清洗" → "针对 XX 设计多阶段清洗方案，有效数据占比从 X% 提升到 Y%"
6. **量化结果用绝对数字**："从 10 小时缩短到 5 分钟" 比 "效率提升 99%" 更有画面感
7. **ATS 关键词矩阵**：明确写出 RAG / Chroma / FastAPI / 评估指标等关键词（只写真会的）
8. **RAG 项目要写出差异化**：10 个候选人 8 个写 RAG，写"规则+语义分块""评估体系"这类深度点，让面试官想追问
9. **项目 1-3 个，在精不在多**
10. **自我评价 = 一句话画像 + 证据**（不写空话）

## 二、应用到余剑简历（v2，全部真实）

- 求职意向加括号：AI 应用开发实习生（具备 RAG 项目上线经验）
- 开头加 GitHub + 上线链接
- 项目 1 三条全部重写：链路（决策：分层切分/持久化）→ 评估体系（12 条评估集，75/83/92%）→ 溯源机制（引用编号）
- 项目 2 只写真实完成的工具调用 demo，不写未完成的行业雷达
- 技能只列真实会用+能讲两句的；**不写 LangChain/微调/多 Agent**（没做过）
- 自我评价一句话画像："专注大语言模型应用落地，独立完成并上线 RAG 系统，重视效果评估与可溯源"

## 三、投递前自检（每条都能讲 2 分钟才算数）

- [ ] 83% 是怎么算的？（12 条评估集，top-3 命中）
- [ ] 为什么选 bge-small-zh-v1.5？（中文效果好、轻量）
- [ ] 为什么 300 字/块 + 50 重叠？（语义完整 vs 检索精度）
- [ ] 上线链接能打开、能演示吗？
- [ ] 项目 2 的 JSON 工具调用链路能讲清吗？

讲不清的，投递前先练会——简历包装的上限 = 你能讲深的上限。
