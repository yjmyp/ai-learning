# Agent 项目选题分析（2026-08-15 深夜 · 你的 50+ 条想法全归类）

> 原则：以腾讯 JD 为标尺——项目要"真实场景 + 能演示 + 有 eval + 能回答为什么做"。

## 一、你的想法全清单归类（A 求职 / B 调研 / C 创作 / D 长线）

### A 档：求职直接相关（做成 skill 插件，服务自己）
- 帮助面试的 agent、蒸馏自己用来面试（项目拷打）、帮助秋招/找实习的 agent、找适合自己网课的 agent
- 评估：这四类可合并成一个"**求职助手 skill 包**"，复用 RAG（把 JD/面经/自己的项目做成知识库）

### B 档：行业/市场调研类（信息价值高、可演示）⭐
- 行业上下游调研（所有行业排列、热门/冷门、选中间偏少、AI 切入点）
- 找商业机会（热点、政策、方向预判）、调研市面上 agent 的 agent
- 垂类市场检索（二手奢侈品、谷子/labubu 卡片、漫展）
- 评估：**"行业机会调研 Agent"最适合做项目 2 主体**（论证见下）

### C 档：创作/蒸馏类（有趣但有版权/伦理边界，2 周做不完）
- 蒸馏作家/创业者/艺术家/建筑师/jack、小说动漫化、电视剧抽象改编、漫画翻译、书籍动画、数字人口播、调香、创造新食物、AI+中医健康
- 评估：先记着，不投入；"蒸馏自己"除外（A 档已用）

### D 档：自我进化/生态类（最前沿，长线探索）
- 让 agent 搭建 agent、自动搜集新 skill、自我运行改变自己、学习如何进化
- 评估：近期只做其中一小块——"调研市面上 agent/skill 的 agent"当 skill 练手；完整"自我进化"留到实习后

### 特殊：命理类（奇门遁甲/紫薇/六爻/梅花易数）
- 电脑端已有现成排盘技能（奇门、八字紫微），可低成本做一个"**命理咨询 agent**" skill，展示"调用领域工具构建 agent"的能力——可选加分项

## 二、项目 2 定题论证：行业机会调研 Agent（行业雷达）

**为什么是它：**
1. **真实场景**：找工作选行业、创业找机会、投递前调研目标公司都直接用 → 面试讲"我做了个工具，并用它调研了贵司"是王炸叙事
2. **全覆盖 JD 四大机制**：Planning（多步调研计划）→ Tool Use（搜索/网页/文件）→ Memory（调研进度与发现存档）→ Reflection（报告自检、缺料补查）
3. **自带 eval**：准备 10 个行业任务，核对报告完整性/数据真实性 → 直接对齐"评测体系"加分项
4. **可扩展多 Agent**（加分）：主编 Agent 拆任务 + 研究员子 Agent 并行调研
5. **和你的方向完全一致**：你就是"用 AI 找机会"的人，动机真实

**MVP 范围（2 周内）**：
- 第 1 周：单 Agent ReAct 循环 + 搜索工具 + 结构化报告模板（行业热度/冷热度/中间带/AI 切入点）
- 第 2 周：记忆（调研存档）+ 反思（报告自检）+ eval（10 任务 ×10 次）+ Streamlit 演示页
- 可选：LangGraph 版对照（跑通即停，重点讲选型）+ 多 Agent 版

**配套 skill 插件（同一项目里体现"生态"）**：
1. 面试拷打 skill（蒸馏自己：项目+RAG+面试 agent）
2. 网课匹配 skill（轻量）
3. 命理咨询 skill（用现成排盘，可选）

## 三、砍掉/缓做的理由（客观）
- "蒸馏别人"：有版权/肖像/伦理风险，简历上写了反而减分
- 娱乐生活类（找搭子/打卡/省钱）：没有技术深度，面试讲不深
- 自我进化：概念前沿但 2 周无法做出可演示、可评估的成果
- 内容创作类（小说/动漫/数字人）：2 周做不完，且偏离"Agent 工程"主线
