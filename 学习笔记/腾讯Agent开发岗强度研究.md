# 腾讯 Agent 开发岗强度研究（2026-08-15 深研）

> 来源：《腾讯2027校招拆解：Agent开发成了独立岗位，Claude Code成了必备技能》（2026-08-14 发布）+ 字节/腾讯面经检索
> 用途：定义"要做到什么地步"的硬标准，直接对照我们的计划

## 一、腾讯 2027 校招 Agent 开发工程师 JD（原文拆解）

### 岗位描述（4 条）
1. 智能 Agent 系统架构设计与开发：**多 Agent 协作框架、任务规划与调度、工具调用与执行引擎**
2. 设计实现 Agent 的**记忆系统、推理链路、决策机制**，提升复杂业务场景下的自主性与可靠性
3. 搭建 **Agent 评测与质量保障体系**：效果评估、持续优化、性能与成本管控
4. 跟踪技术前沿，技术预研与落地

### 岗位要求（6 条）
1. 一门主流语言（Python/TypeScript/Go）+ 扎实数据结构算法
2. 深入理解 Agent 原理：**Planning / Memory / Tool Use / Reflection**
3. 熟悉主流框架：**LangGraph / AutoGen / CrewAI / MetaGPT**，有实际搭建经验
4. 了解大模型原理 + Prompt Engineering，能设计高质量系统提示词与工具描述
5. 独立调研与技术选型能力
6. 系统思维与问题解决

### 加分项（4 条）
- Agent 系统构建经验（自主任务执行、多 Agent 协作、复杂工作流编排）
- **Agent 评测与质量体系建设经验**
- RAG 搭建经验（向量检索、知识图谱）
- 开源项目 / 技术博客 / Agent 应用作品展示

## 二、关键信号（对你战略级重要）

1. **Agent 开发是独立岗位**，不再是"算法/后端 JD 里的一段话"——方向选对了
2. **评测体系单独占一条**：腾讯在生产里吃过"Demo 惊艳、上线拉胯"的亏，所以"效果评估、性能、成本"是硬要求；青云计划里还有"Agent 前沿评测研究"顶级课题 → **eval 不是加分，是标配**
3. **框架要求全是开源**（LangGraph/AutoGen/CrewAI/MetaGPT）→ 公司要的是会用社区工具的人
4. **作品 > 竞赛奖牌**：JD 加分项全是"作品展示、技术博客、独立开发过" → 一个真实项目 + 一篇复盘博客，分量可能超过水实习
5. **Claude Code/Cursor 是必备项**（AI 全栈岗原文写进要求）→ AI 编程工具熟练度是隐形门槛
6. 全部远程面试，地域不是障碍

## 三、字节/腾讯面经补充考点（技术深度）

- 腾讯：**MCP、A2A 协议与生态**讲不清楚 = 被认为只跑过 toy example
- 字节：ReAct 在长任务中的**上下文线性增长**问题（IterResearch/Deep Research 框架）；工具调用**防幻觉**；多 Agent 下**效率与准确性权衡**；**短期/长期记忆压缩**；模型**输出控制**
- 项目拷打灵魂问题：**"现在有了 Claude Code，为什么还要重复做类似项目？"**——必须能答
- 工程细节：SSE 流式输出、缓存、并发限制、RAG 系统设计

## 五、结论：你"要做到什么地步"的量化标准

1. **项目 2 必须能演示**：网页版可访问，真实输入 → 规划 → 调工具 → 输出报告
2. **项目 2 必须带 eval**：至少 10 个任务，每个任务跑 ≥10 次，记录成功率（借鉴开源 AgentGuide：回归集/对抗集/多轮硬题）
3. **必须能回答灵魂问题**：有了 Claude Code 为什么还做？→ "我要理解原理，工具是我自己写的，AI 只是加速器"
4. **必须讲清选型**：为什么自研循环 vs LangGraph，为什么 Chroma vs Faiss
5. **必须有一篇技术博客** + GitHub 开源
