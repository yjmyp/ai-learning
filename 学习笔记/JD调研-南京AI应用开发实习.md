## 四、关键词频次（30+ 家真实 JD 校对）

**必会（出现 >15 次）**
- Python
- LLM API 调用（DeepSeek/Qwen/GLM/OpenAI/通义）
- RAG / 知识库问答
- Prompt 工程
- 向量数据库（Chroma / Milvus / Faiss 至少一个）
- Agent / 智能体
- FastAPI / 后端接口

**常见（5-15 次）**
- LangChain / LangGraph
- Function Calling / 工具调用
- SQL
- 记忆 / Memory
- 评估 / 评测（eval）
- MCP（趋势上升）
- Docker
- 全栈 / 前端基础
- GitHub 项目 / 作品集

**加分（<5 次）**
- 微调（SFT / RLHF / LoRA，了解级）
- 知识图谱（Neo4j）、GraphRAG
- 重排（rerank）
- 多模态
- 竞赛 / 论文
