# chat.py 完整链路图（请求 → 响应）

## 数据流向总览

你输入"你好"（input）
   ↓
user_input = "你好"
   ↓
messages = [{"role":"user","content":"你好"}]          ← 你问的
   ↓
data = {"model":"deepseek-chat","messages":messages}
   ↓
requests.post(...)  →  寄给 DeepSeek
   ↓ （等 1~2 秒）
r = 回信
   ↓
r.json() → ["choices"] → [0] → ["message"] → ["content"]
   ↓
reply = "你好！我是DeepSeich..."                       ← AI 答的
   ↓
messages 又记一笔（AI 说的）
   ↓
print("AI：你好！...")

## 代码逐段对照

# ========== 发送（你 → DeepSeek）==========

# 1. 把你说的记进记录本（content = 你问的）
messages.append({"role": "user", "content": user_input})

# 2. 写订单（点哪道菜 + 全部聊天记录）
data = {
    "model": "deepseek-chat",
    "messages": messages,
}

# 3. 寄出去（地址 + 会员卡 + 订单 + 限时）
r = requests.post(url, headers=headers, json=data, timeout=60)

# ========== 接收（DeepSeek → 你）==========

# 4. 检查回执，有问题立刻报警
r.raise_for_status()

# 5. 拆回信，一层层取 AI 的回答（content = AI 答的）
reply = r.json()["choices"][0]["message"]["content"]

# 6. 把 AI 的回答也记进记录本（下次它还"记得"）
messages.append({"role": "assistant", "content": reply})

# 7. 打印给用户看
print(f"AI：{reply}")

## 关键记忆点

- 请求里的 content = 你问的；响应里的 content = AI 答的（别搞反）
- messages = 记录本，你和 AI 每说一句都记一笔
- 第 5 步是"拆套娃"：回信 → choices 列表 → 第1个 → message → content
- 每次循环 = 完整的"寄信 → 回信"一轮
