📖 概念速查（点开看）

Token
文本最小处理单位，英文≈单词、中文≈字/词。上下文窗口按 token 计（DeepSeek 约 12 万）。
Prompt
给模型的指令。技巧：角色 + 示例 + 输出格式约束。chat.py 里就是 messages 数组。
上下文窗口
模型一次能接收的最大 token 数，超出会截断。所以 RAG 要先检索精选，不能全塞。
Embedding
把文本变成向量，语义相近则距离近。rag2 用 bge-small-zh-v1.5，encode 后归一化。
余弦相似度
向量夹角越小越像。Chroma 返回的是距离，rag2 里用 1 - 距离 转成相似度。
RAG
检索增强生成：先查资料再回答。流程 = 切块 → 向量化 → 入库 → 检索 → 拼 Prompt → 生成带引用。
BM25
关键词检索算法：词频有上限（k1 饱和）+ 稀有词权重大（IDF）+ 长度归一化（b）。中文按相邻双字切词。
混合检索
向量管语义、BM25 管词面精确，双路召回再融合。rag2 权重 0.7 向量 + 0.3 BM25，用 min-max 归一化对齐。
Chroma
本地持久化向量库。add 存四样：id / texts / metadatas / embeddings；query 按余弦距离取最近。
向量数据库
存向量的库：Chroma / FAISS / Milvus / Qdrant。小项目 Chroma，生产可换 Milvus。
Agent
大模型 + 规划 + 工具 + 记忆，能自主完成任务。核心循环 = 思考 → 调用工具 → 看结果 → 再思考。
ReAct
Reasoning + Acting 循环：先推理下一步，再行动（调工具），观察结果后继续。agent_calc.py 就是这个。
Function Calling / Tool Calling
让模型按 JSON Schema 输出结构化调用。agent_tool_guard.py 校验 5 类坏输出：未知工具/缺参/类型错/非对象/非法 JSON。
Memory（记忆）
短期记忆 = 对话上下文；长期记忆 = 向量库存历史。项目 2 要做的部分。
MCP
模型上下文协议：统一工具/数据怎么接入模型的标准，JD 高频词，了解级即可。
LangChain / LangGraph
Agent 开发框架。策略：自研循环为主，框架只做对照讲选型，不深耕。
Rerank（重排）
召回 top-k 后再精排。rag2 用 TF-IDF 字符重排，把向量候选重新打分排序。
评估集 / Eval
问题 + 期望命中资料，算 top-k 命中率。12 条基线：top-1 75% / top-3 83% / top-5 92%（251 块时测）。
重试退避（指数退避）
工具调用失败后按 1s→2s→4s 递增等待重试，最多 3 次，避免把故障放大。字节真题考点。
熔断器（Circuit Breaker）
同一工具连续失败 N 次后熔断，不再调用，直接走降级路径（换工具/兜底回答）。防止雪崩。
循环检测
记录最近 N 轮 Action，发现"同一工具 + 同一参数"重复调用就强制终止，是 Agent 防死循环的核心。
最大轮数限制
ReAct 循环设 20 轮上限，超时/超轮强制退出并返回"任务未完成，已记录日志，请人工介入"。
异构数据解析
RAG 不只处理纯文本：图片用 OCR + 多模态 Embedding，表格结构化解析（保留行列）+ 独立索引。阿里真题。
Hit Rate / MRR / Answer Correctness
召回命中率 / 平均倒数排名（首个正确答案排第几）/ 答案正确率。阿里要求 RAG 量化：Hit Rate 87%、MRR 0.72、AC 84%。
FDE
前端部署工程师（Frontend Deployment Engineer）：把大模型部署进企业内网、定制微调、接企业数据。领英预言三岗位之一，起薪 3 万/最高 10 万。
Prompt 注入
攻击者把指令藏在用户输入/文档里骗过模型。防御：角色边界 + 输入输出隔离 + 敏感操作权限控制。Agent 安全必讲。
多智能体协作
分工式 Agent：规划 Agent / 执行 Agent / 反思 Agent 各干一段。了解即可，自研循环为主。
LlamaIndex / CrewAI / AutoGen / Dify / Coze
框架对照清单：LlamaIndex 偏数据/RAG，CrewAI/AutoGen 偏多智能体编排，Dify/Coze 偏低代码平台。选型时横向对比讲。

🎤 高频 3 问（门禁必背）

为什么用 bge 而不是别的模型？
中文检索效果好 + 本地缓存不联网 + 数据量（254 块）小模型够用；超过 1 万条再换 bge-large。
你的文本怎么切分？
300 字/块 + 50 字重叠，段落感知滑动窗口；下一版计划做语义切分（按句子嵌入相似度断点）。
检索失败怎么办？
已做：向量 + BM25 混合召回 + 重排；待做：相似度低于阈值就拒答，不硬答。

🔥 必杀题 5 道（参考要点，自己组织语言）

1. 为什么 bge-small 而不是 m3e？
MTEB 中文检索里 bge-small 速度/精度平衡，和我的数据规模匹配；规模超 1 万条会换 bge-large 并降采样。
2. Chroma 挂了怎么办？
本地持久化 + 定期备份 collection；生产环境加副本，当前 Demo 单机够用。
3. 切分切断重要实体怎么办？
目前段落感知滑动窗口缓解；下一版按句子嵌入相似度做语义切分。
4. 你的生成幻觉率是多少？
未系统评测，但做了引用溯源可人工校验；后续用 Ragas 跑 faithfulness 指标。
5. top-3 全错怎么办？
阈值过滤（相似度低于 0.7 拒答），当前是待优化点——主动暴露短板比被问穿安全。

🎯 2026 大厂真题（真实面经）

🔴 字节：Agent 调三个工具死循环了，异常处理在哪写的？
考点是 Agentic Engineering（控 AI 不失控）。标准答法：① 工具失败指数退避重试 ≤3 次 ② 连续失败熔断走降级 ③ 记录最近 N 轮 Action 做循环检测 ④ ReAct 最大 20 轮上限 ⑤ 兜底返回"任务未完成，已记录日志，请人工介入"。
🟢 阿里淘天：45 分钟 14 连问（从 RAG 到幻觉）
① 异构数据：图片 OCR + 多模态 Embedding；表格结构化解析保留行列 + 独立索引；多路召回（向量+关键词+表格）→ Rerank 融合。② 量化指标：解析成功率 99.2%、表格结构保留率 95%；RAG Hit Rate 87%、MRR 0.72、Answer Correctness 84%——没有量化 = 没做核心工作。③ 幻觉治理：检索侧（混合检索+重排）+ 生成侧（约束解码+溯源标注）+ 后处理（小模型验证）。
🔵 腾讯：LLM 和 Agent 有什么区别？
联系：Agent 每次决策都由 LLM 做出。区别：LLM 是无状态文本生成，用完即忘、改变不了世界；Agent 是围绕 LLM 的执行系统，补上工具（输出→真实动作）、循环（多轮推理+行动）、记忆（跨轮状态）。一句话：LLM 负责想，Agent 负责想完了真去干。追问"网页对话助手算 Agent 吗"→ 看有没有 ReAct 闭环，单次问答不算。
🟠 阿里灵魂问：项目自己写的还是抄的？
别用嘴证明。证据链：GitHub commit 历史（自己提交）、能现场改参数并预测结果变化（chunk/top_k 改完说出会怎样）、eval 数字（83% 哪来的）、可在线演示。
