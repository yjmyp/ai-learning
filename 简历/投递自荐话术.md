## 长版（网申开放题 / 邮件自荐，约 500 字）

尊敬的招聘团队：

您好！我是南京邮电大学网络工程专业 2027 届本科生，正在寻找 AI 应用开发方向的实习机会（Agent 开发 / RAG 检索）。过去一年我围绕大模型应用独立完成了两个从 0 到 1、可上线可验证的项目，希望有机会加入贵团队。

**项目一：OfferAgent 求职智能体（Agent 工具调用与工作流引擎）**
面向求职场景的一站式工作台，将"自我画像 → 岗位筛选 → 匹配打分 → 投递话术 → 投递记录 → 面试复盘"串成完整链路。核心设计：
- 打分由"模型自由给分"改为五维本地加权，同一岗位重复打分标准差从 2.36 降至 0.00（可复算、可审计）；
- 10 个工具统一 Schema 注册表 + Plan/Reflect 节点，30 类正常与异常输入守卫判定 30/30，错误结构化回填、模型自纠；
- 自研 MCP 服务端（stdio + JSON-RPC 2.0），执行类工具由人确认，投递前重访链接拦截失效岗位；
- 对外 API 层用 Java/SpringBoot 3 + JDK 21 + MySQL + Redis + Docker 重写：热点查询缓存 464ms→51ms，API Key 鉴权 + 限流，19 个单元/集成测试 0 失败。

**项目二：RAG 检索问答服务**
面向私有资料的安全问答，全链路自研（未套 LangChain）：多格式解析 → 结构感知切分 → bge 向量化 → 混合召回 → 多特征重排 → 句级引用定位。在 240 条自建评估集上量化验证：混合检索 R@5 93% / MRR 0.796，加重排后 R@5 95% / MRR 0.856；可信拒答误拒率 2%；单机稳态约 20 QPS，Docker 一键部署。

两个项目均带自建评估集、压测报告与 CI，代码在 GitHub 仓库，并有在线演示可免密直接体验（简历链接内）。我可以尽快到岗实习，期待您的回复。
