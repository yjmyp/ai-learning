### RAG 检索问答服务（个人项目）　2026.07 – 2026.08

自建 240 条评估集（200 条可回答 + 40 条库外与难负例）：在 33 篇 / 740 块语料上混合检索 R@5 93%、MRR 0.796、P99 延迟 69ms；库外问题误拒率 1%。

技术栈：Python ｜ bge-small-zh-v1.5 ｜ Chroma ｜ FastAPI ｜ Streamlit ｜ DeepSeek API

- 设计并实现混合检索 + 重排链路：BM25 与向量用 RRF 融合召回后做多特征重排，并在命中块内做句级引用定位（返回支撑答案的句子与字符偏移，前端可高亮）。
- 自建 240 条评估集做消融评测（200 条可回答问题逐条绑定标准答案块，40 条库外与难负例）：量化定位「混合召回解决未召回到、重排解决未排到前面」的分工；多查询改写实测性价比低（延迟明显上升、精度未提升）故默认关闭。
- 实现拒答门禁与答案级自检：拒答阈值在评估集上网格搜索校准；对数值型问题追加答案级自检，库外问题误拒率 1%。
- 端到端链路自研实现（未使用 LangChain 封装）：多格式解析（txt / md / pdf / docx / html / csv / xlsx，其中 xlsx 用 zip + XML 自解析，不依赖第三方库）→ 结构感知切分 → 向量化 → 混合召回 → 重排 → 生成。
- 服务化与运维：FastAPI + SSE 流式输出 + API Key 鉴权 + 限流 + 存活 / 就绪探针 + 增量索引（改一篇只重算一篇）+ trace 计量（端到端延迟与单次成本约 0.0003 元）；启动预热把首个请求从 15.3s 降到 62ms，单机压测稳态约 20 QPS，Docker 一键启动。
