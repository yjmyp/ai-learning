## 二、项目起源与演进

1. **CLI 流水线（run_all.py）**：me.txt → 生成画像 profile.md → 对比 JD 出匹配报告 → 结合简历出修改建议。三阶段提示词集中在文件顶部（PROMPT_PROFILE / PROMPT_MATCH / PROMPT_ADVICE），路径集中在 PATHS 字典，工具函数 read_file / save_file / ask_model。
2. **Web 应用 v1**：升级为 Streamlit 单文件 `offer_agent_app.py`——7 大模块（仪表盘/画像/岗位库/匹配分析/话术/简历建议/设置）+ plotly 图表（环形评分/五维雷达/排名条形图）+ 深色侧边栏。
3. **Web 应用 v2（当前）**：联网抓取 + 自然话术 + 卡片 UI（本轮刚完成）。

## 三、用户对 OfferAgent 的全部要求（散点整理）

### A. 功能要求
1. **岗位库 + 匹配分析必须联网**，不要手动粘贴 JD；粘贴招聘页 URL 一键抓取（已实现：直连 + r.jina.ai 兜底）
2. 匹配报告要有**同类岗位对比建议**（该岗位与其他公司/更符合的岗位横向比，投递优先级）——已列入 PROMPT_MATCH 模板
3. 要能**批量筛选市面上 Agent 开发岗**，过滤后批量投递
4. **自动投递**：直接帮我投，并优化投递话术和简历（卡在 BOSS 登录，用户曾跳过接管）
5. 增加"同类岗位比较"类功能、以及"你还推荐加什么功能"的建议（第二项是问我，不是功能）

### B. 体验 / 话术要求
6. **话术必须自然**：像真人微信聊天，直接展示项目经验但**不能生硬**，不要简历复读机、不要"您好我是 XX 大学 XX 届"模板开头（已重写 PROMPT_TALK，60–100 字）
7. 页面要**好看**：参考 GitHub 高星项目升级（已采用 Resume-Matcher 25k⭐ 架构思路，Streamlit 实现）
8. 提示词要**变量化、可增删**（PROMPT_* 集中管理，已满足）

### C. 排除规则
9. **排除"专门点名要求网络工程专业"的岗位**（如彩讯科技 JD："计算机、软件工程、网络工程、人工智能等相关专业"）——已实现自动检测，7/7 测试通过

### D. 工程 / 上线要求
10. 项目要**真正能上线**（可推 GitHub → share.streamlit.io 公开访问，用于面试展示）
11. 工程类杂活直接代做，不要浪费时间；不要让我打很多字
